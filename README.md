# US Presidents Showcase

A data visualization website focusing on US Presidents, built with Vue 3, Vite, TypeScript, Pinia, Element Plus, and ECharts.

## Features
- **Internationalization**: English and Chinese support.
- **Responsive Design**: Compatible with PC and Mobile.
- **Visualization**: Timeline and Mind Map using ECharts.
- **Data**: President list with search and filtering.

## Tech Stack
- Vue 3 + TypeScript + Vite
- State Management: Pinia
- UI Framework: Element Plus
- Visualization: ECharts
- I18n: Vue I18n

## Running with Docker (Recommended)
The application runs on port **3000**.

```bash
docker-compose up -d --build
```

## Local Development

```bash
cd frontend
npm install
npm run dev
```
